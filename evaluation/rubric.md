# Blind diagnosis rubric

Reviewers receive only a blind ID, diagnosis, and immutable evidence hash. Mode,
model, tool-call trace, usage, and hidden truth remain concealed. Family uses exact
registered labels. Root cause requires the registered concepts, and location must
fall in the pre-registered file and line range. Inconclusive precision/recall is N/A
when the suite contains no cases with an adjudicated inconclusive truth.
