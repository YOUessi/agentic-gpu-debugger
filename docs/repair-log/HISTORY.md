## 如何阅读这些记录

每篇按问题主题分轮说明现象、原因、应该修法、实际修改、测试结果和后续边界。
不是每个 Git 提交都等于一轮，也不是每条外部审阅意见都已被证实。
证据分为：本轮核对的源码/原始报告；已有仓库文档的历史记录；用户转述的外部分析；
无法恢复的缺失资料。正文会明确说明，不把它们混成同等可信的“已验证”。
