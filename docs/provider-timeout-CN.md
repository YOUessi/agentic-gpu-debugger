# 请求超时配置

`GPU_AGENT_LLM_TIMEOUT_SECONDS` 控制单次请求的绝对期限，默认仍为 60 秒；
允许有限正数且不超过 600 秒。实际期限还受整个 Agent 任务的剩余时间约束。
例如 `GPU_AGENT_LLM_TIMEOUT_SECONDS=120` 不会增加总调用次数或任务总时限。
新调用的 STARTED / 终态记录包含 `request_timeout_seconds`；旧记录没有该字段时
保持未知，不补造配置。

这不是自动重试开关。超时仍记为 UNCERTAIN，不自动重复发送，未返回的 usage
仍为未知，不能按零费用统计。开发集 e80ce75 的六次 60 秒超时只能证明客户端
到达期限，不能证明服务端未收到请求，也不能证明延长期限必定解决问题。

2026-09-26 的定向复测采用新 run、显式 120 秒配置，只选原超时单元，各运行一次；
旧记录不恢复、不覆盖，不与新版本结果合并计算基线指标。
